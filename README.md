# mobile-app-prototype

Dating app prototype to accompany the case study. Spark opens on Discover: a deck of sample cards you can save, skip, and open.

Drag a card right to save and left to skip. Tap the top card for the detail sheet. Connect and Save leave the deck where it is.

## Run

```bash
npm install
npm run web
```

`npm start` opens the Expo dev server for a device or simulator. `npm test` checks the swipe rules, and `npm run typecheck` runs the TypeScript compiler.
