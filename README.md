# mobile-app-prototype

Dating app prototype to accompany the case study. Spark is a small Expo app with a deck of sample profiles.

Drag a card right to like and left to pass. Pass and Like do the same thing.

## Run

```bash
npm install
npm run web
```

`npm start` opens the Expo dev server for a device or simulator. `npm test` checks the swipe rules, and `npm run typecheck` runs the TypeScript compiler.
